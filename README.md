# String Collection in C

Учебный проект на языке C, реализующий абстрактный тип данных для работы с коллекцией строковых элементов.  
Программа поддерживает хранение символов и строк, а также базовые операции над строками и коллекцией.

## Тема

**Вариант №25 — строка / коллекция строк**

Реализованы операции:

- конкатенация двух строк;
- получение подстроки с индекса `i` по `j`;
- получение элементов коллекции с `i` по `j`;
- разбиение строки на слова;
- хранение элементов двух типов: символ и строка;
- автоматические тесты для проверки корректности работы.

## Описание файлов

### `main.c`

Главный файл программы.  
Содержит меню пользователя, обработку ввода и вызов функций из модуля `string_collection`.

Через меню можно:

- добавить символ в коллекцию;
- добавить строку в коллекцию;
- вывести коллекцию;
- выполнить конкатенацию строк;
- получить подстроку;
- получить часть коллекции;
- разбить строку на слова;
- запустить тесты.

### `string_collection.h`

Заголовочный файл.  
Содержит описание структур, перечислений и прототипов функций.

В нём объявлены:

- типы ошибок `SCStatus`;
- типы элементов `SCElementType`;
- структура элемента `SCElement`;
- структура коллекции `StringCollection`;
- функции для работы с коллекцией и строками.

### `string_collection.c`

Основной файл реализации.  
Содержит всю логику работы с коллекцией:

- создание и удаление коллекции;
- добавление строк и символов;
- получение элемента по индексу;
- печать коллекции;
- динамическое расширение массива;
- конкатенация строк;
- получение подстроки;
- получение части коллекции;
- разбиение строки на слова.

### `tests.c`

Файл с автоматическими тестами.  
Проверяет корректность основных функций программы с помощью `assert`.

Тестируются:

- конкатенация строк;
- получение подстроки;
- добавление элементов;
- получение элементов по индексу;
- получение части коллекции;
- разбиение строки на слова.

## Особенности реализации

- Коллекция реализована через динамический массив.
- При нехватке места массив автоматически расширяется.
- Для строк используется динамическое выделение памяти.
- После завершения работы память освобождается через `sc_destroy`.
- Символы хранятся как строки длины 1, но имеют отдельный тип `SC_ELEMENT_CHAR`.
- Для обработки ошибок используется перечисление `SCStatus`.
